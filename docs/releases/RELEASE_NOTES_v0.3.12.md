# Godmode v0.3.12

The trust release: what the record cannot see now says so out loud. A claim
below the verified grade citing a command with no attestation behind it names
that gap in its own advisories - "observed" never silently reads as "checked".
Quantities that disagree across same-subject claims are quoted against each
other at write time with the two honest exits. `godmode topology` maps each
session's record-kind transitions and names the ones seen mostly in sessions
that ended in incidents - counts and shares, association not cause, honest
refusal below four sessions. `godmode digest` tells the archive as dated
prose, assembled verbatim from record fields. The skill lint gains a bundle
facet (dead links and orphans in the skill's own directory graph), the push
preflight scans commit history for private terms, the advisory posture becomes
a declared `nag_posture` knob (quiet/standard/strict, anything else refused
loudly), and the doctrine renders into Cursor/Copilot/generic instruction
files from the same canonical constants the session brief injects.

Three same-day field reports shaped the fixes: `remember` accepts a whole
record as one quoted prose string (a usage error that loses an incident is
worse than a derived subject), the stop gate's echo crosses host codepage
boundaries as plain ASCII, fenced code blocks and conditional sentences no
longer arm the completion gate, reported speech ("the vendor claims X") is no
longer judged as this agent's claim, and `verify --timeout` lets a full-suite
attestation declare its own budget. The statusline badge wears the full
GODMODE label, colored by its enforcement marker.

## Verifying

- `python -m unittest discover -s tests` — the full suite (3,100+ tests; four
  chunks keep any one run bounded, `godmode verify --timeout` attests each).
- `godmode topology` — the transition map over your own archive; below four
  sessions it refuses with the floor named.
- `godmode digest --since 7` — the last week of the archive as dated prose.
- `godmode claim "the suite is green" --cite "cmd:python -m unittest"` — watch
  the advisory name the unattested command; then run the same command through
  `godmode verify` and record again to see the advisory clear.
- `godmode precheck --preflight` — tree scans, commit-history term scan, and
  census debt in one report, on a disposable worktree.
