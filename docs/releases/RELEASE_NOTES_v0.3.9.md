# Godmode v0.3.9

The utilization release: the machinery that existed now reaches the moment it was
built for. A completion declared without a record is blocked once at the stop with
the exact recording command as the reason; the session brief closes with the
commands the archive's own state demands instead of inventory; raw check commands,
fix-shaped prompts, and ship-shaped prompts each draw the one verb their moment
calls for, once per session. Two new stop advisories name the zero-information run
shapes (a green check re-run with nothing changed, a failed command re-run with
nothing changed), the census gains atlas, checklist, and evidence-richness
families plus an oversight pulse over approval streaks, the preflight probes for
unstated assumptions and confirms its own cleanup, and claim resolutions gain a
`superseded` outcome so replacement is never mistaken for reversal.

Four same-day field reports from independent projects shaped the fixes: CLI
argument aliases (`claim --text`, positional `checkpoint`), a reply splitter that
no longer manufactures claims out of version numbers or status tables, sibling
obligations collapsed to the newest with the elder named for retirement, and a
claim echo that dies rather than nag a restarted session about a reply it never
wrote.

## Verifying

- `python -m unittest discover -s tests` — the full suite (3,000+ tests; four
  chunks via `scripts/dev/run_with_flaky_retry.py` keep any one run bounded).
- `godmode doctor` — calibration, census (with `evidence_richness`), and the
  oversight pulse ride the payload; `next_actions` closes the session brief.
- `godmode precheck --preflight` — census debt, the assumption probe, and
  `cleanup: confirmed` in one report, on a disposable worktree.
- `godmode hooks status` — enforcement grading; a live host deny chronicles the
  HARD proof this release's field reports asked about.
