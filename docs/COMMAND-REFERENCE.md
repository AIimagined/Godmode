# Command reference

Every top-level verb, its purpose, and a command that verifies it is real. Generated by `scripts/dev/build_command_reference.py` from the CLI's own parser (`scripts/godmode_runtime/godmode_console.py`'s `_build_parser`) - regenerate rather than hand-edit when a verb's help text changes; `tests/test_command_reference_drift.py` fails if this file and the live parser ever disagree. Most rows verify with `--help` (always resolves, always accurate); a verb that already carries a dedicated test module or an authored README section points the Verify column at that instead. See `skills/godmode/references/godmode-command-surface.md` for the same surface from the routing skill's side.
