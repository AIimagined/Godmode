- In an initialized project, a command that weakens Godmode's own protection now needs your approval the same way a push or release does: `godmode config set uninitialized off` (machine-wide or `--repo`), `godmode config mode advise`, a `git config` write of a `godmode.*` key, and any write to the machine-wide `godmode-settings.json`. The host asks when you are present and the command is refused, with a staged-approval remedy, when nobody is. Reading a setting and moving a switch to its stricter value (`guard`, `strict`) stay free.
