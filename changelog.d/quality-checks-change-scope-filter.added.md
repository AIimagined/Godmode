- The publication and name-reference quality checks now report on what changed instead of the whole tree by default: `--filter added|file|all` picks which findings count, and `--fail-level harm|error|warning` picks which of those fail the run. A finding on a line your change did not touch is labelled pre-existing and never blocks it; the release check and CI keep the full-tree, fail-on-anything behavior. The accepted-reference list is now keyed to a reference's exact text rather than its line number, so an unrelated edit that moves the line no longer breaks an accepted entry.
