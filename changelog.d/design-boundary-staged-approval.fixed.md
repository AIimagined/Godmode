- An edit refused by the design boundary in `.godmode-boundaries.json` can now be approved: `authorize stage --operation "edit file <path>"` accepts it instead of answering that read-only inspection needs no capability, and the approval is spent once by the next Edit or Write of that path, while `skill forge`, `skill retire` and `skill restore` on a locked skill take their own approval (`forge skill <name>`, `retire skill <name>`, `restore skill <name>`), so an approval for one file never unlocks a whole-skill command. The refusal prints that command with the plugin's own launcher, ready to run.
