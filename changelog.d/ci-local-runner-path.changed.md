- `scripts/dev/ci_local.py` now runs the committed workflow's Linux jobs through a local Actions runner when one, and Docker, are both found on PATH - real containers instead of this repository's own approximation of the gate list, so a green local run is a stronger signal that the push will be green on GitHub too. Without both of those on PATH, or with `--native`, it falls back to running the gate list as before. Either way it prints which path it took. Windows and macOS legs are never run through a container; they only ever run natively, on a machine of that OS.
