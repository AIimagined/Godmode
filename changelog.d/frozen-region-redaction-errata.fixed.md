Errata for `docs/releases/RELEASE_NOTES_v0.3.26.md`: those notes state that a frozen region's editor view "is shown only those parts, with a visible marker where text was withheld." That describes `redact_immutable` (`scripts/godmode_runtime/godmode_mutableregions.py`), which builds exactly that view - but nothing in `hooks/` or `scripts/` calls it, so no Read path actually delivers a redacted view to any editor. What is live is the other half of frozen-region enforcement: `edit_verdict`, wired into `hooks/godmode_session_hook.py`, refuses a patch whose span falls outside a file's declared editable region regardless of whether the frozen text was seen. Frozen regions refuse edits; the redacted editor view described in the 0.3.26 notes is not delivered.
