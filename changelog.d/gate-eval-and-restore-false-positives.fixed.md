`claude plugin eval ...` runs with `--no-publish` (and no `--publish-report`) no longer ask as a release: the generic release/external-write pattern matched the bare word `publish` anywhere on the line, including inside `--no-publish`, so a run that explicitly turned publishing off was asked about as though it published. A bare run (no publish flag at all) still asks, since publishing to claude.ai is that command's own default when the account supports it, and `--publish-report` still asks even alongside `--no-publish`, since it forces publishing back on - only `--no-publish` on its own is local. `claude plugin eval init` (writes eval scaffolding locally) never publishes and is unprotected regardless of any publish flag. `git restore --staged <path>` is likewise no longer treated as discarding work: `--staged` alone moves a path from the index back to HEAD, the exact inverse of `git add`, and the working tree is untouched; `git restore <path>` and `git restore --staged --worktree <path>` still ask, since those do discard working-tree content. `hooks/gate_table.json` was regenerated from the updated classifier (`python scripts/dev/build_decision_table.py`).
