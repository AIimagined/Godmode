`claude plugin eval ...` with no `--publish-report` is a local test run and no longer asks as a release: the generic release/external-write pattern matched the bare word `publish` anywhere on the line, including inside `--no-publish`, so a run that explicitly refused to publish was asked about as though it published. `claude plugin eval init` (writes eval scaffolding locally) is the same family. Only `--publish-report` - the flag that actually sends the report anywhere - keeps asking. `git restore --staged <path>` is likewise no longer treated as discarding work: `--staged` alone moves a path from the index back to HEAD, the exact inverse of `git add`, and the working tree is untouched; `git restore <path>` and `git restore --staged --worktree <path>` still ask, since those do discard working-tree content. `hooks/gate_table.json` was regenerated from the updated classifier (`python scripts/dev/build_decision_table.py`).
