- `lessons approve` no longer trusts the agent id alone to tell the approver from the promoter. Promotions and approvals now record the writing process as the operating system reports it (pid, parent chain, the agent host or terminal driving it, and any declared session), and an approval is refused when both resolve to the same process, session, parent or driving program, or when one process started the other - so renaming `GODMODE_AGENT_ID` between the two steps no longer passes. A promotion recorded before this change must be re-minted before it can be approved. THREAT-MODEL.md states the remaining boundary: every process belongs to one local user.
