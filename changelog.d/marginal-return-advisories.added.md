Two new stop-hook advisories name zero-information run shapes: a green streak (the same command passing three or more consecutive times with no edits between - re-running an already-green check adds nothing; record the claim it supports) and a stale retry (a failed command re-run with nothing changed since the failure - the verdict cannot change). Counts only, once per session per shape, the complement of the fix-loop shapes which require edits between runs.
