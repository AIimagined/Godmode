- Project skills change in any session. When nobody is watching, each change - an edit or write, `skill forge`, `skill retire`, `skill restore` - is recorded, reported once per session ("skills/<name> changed (<how>) in an unattended session - review the diff") and listed by `godmode status`. To lock a skill, list it in `.godmode-boundaries.json` (`skills/<name>/**` under `ui.declared`): every one of those writers is then refused in every session, and the skill commands pass only when run `--as-operator` with the password. `skill forge` now accepts `--as-operator`.
