- An agent's own shell call can no longer start an approval: `godmode authorize stage`, `setup`, `grant` and `issue` are refused in every mode - attended, unattended, auto and observe - in any launcher form (the bare launcher, `python scripts/godmode.py`, a quoted path, a PowerShell call, or inside a compound command or a `bash -c` payload), and no staged approval opens them. These verbs raise your password dialog, and a prompt raised on an agent's behalf is one you learn to click through. The refusal names the remedy: type the same command yourself with a leading `!`. `godmode authorize request` and `authorize requests` stay available to agents.
