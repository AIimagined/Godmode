- `tee` and PowerShell's `Tee-Object` are now judged as the writes they are: `cat notes | tee /etc/hosts` asks, as a redirect to the same file would, while `tee` into the working tree stays free. `xargs` is judged by the command it runs. `nl` and `column` now take the fast path as plain reads.
- A claim cited on a pipeline that ends in `tee`, `nl`, `column`, `rev` or a PowerShell object cmdlet (`Select-Object`, `Sort-Object`, `Measure-Object`, `Out-String` and the like) is graded on that filter's exit code, not the run's, so it is no longer graded verified. A pipeline ending in `xargs <command>` is graded on that command.
