- A record served from the archive's on-disk read index now gets the same project-identity check a freshly-read record already gets; an accelerated read used to skip it entirely, so whether a foreign record was caught depended on how much of the archive the index happened to cover. A moved or copied checkout hitting the append-side identity check now gets a clear message naming both identities, and its own `adopt()`-recorded identity, instead of a bare "does not match".
