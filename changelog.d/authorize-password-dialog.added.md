- `godmode authorize stage` now opens a native password dialog when it runs without a terminal, so a refused call can be approved from the chat prompt with `! "<plugin>/bin/godmode" authorize stage --from-last-refusal` instead of a separate terminal window. The dialog is the Windows credential prompt, a macOS dialog with a hidden answer, or zenity/kdialog on a Linux desktop; it shows the exact command, that the approval is spent once, and its expiry. The password goes from the dialog to the approval check in the same process, never through the chat, a command line or the environment, and the dialog path accepts no password from standard input. Cancel stages nothing, a wrong password is refused as before, and a machine with no dialog keeps the separate-terminal message.
