# Purpose

This skill exists so reconciling Godmode's hook manifests into an installed
AI CLI host's native format, and checking that wiring for drift, is one
routed flow instead of three separate hand-built passes.

## Gap evidence

- Hook-contract conformance across shells was proven, but the reach table
  it produced still had to be regenerated by hand afterward.
- A typed host-capability matrix and the diagnostic modules that read it
  were built separately from the mechanism that actually detects,
  reconciles, and repairs a host's wiring.
- Detecting a host, reconciling its manifest, checking it for drift, and
  repairing it with a shown diff existed as three separate pieces of work,
  never as one flow that walks all four steps in order.

## Promise

Given an installed AI CLI host, this skill reads its current wiring, previews
the exact reconciliation before writing anything, applies only after that
preview is shown, and proves the resulting hook mechanism denies a synthetic
protected operation - stopping and reporting verbatim on any shape it cannot
recover from (a malformed file, an unverifiable gap, a probe that does not
come back `HARD`).

Future edits to this skill append their own plain-language evidence above.
