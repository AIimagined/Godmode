# Purpose

This skill exists so reconciling Godmode's hook manifests into an installed
AI CLI host's native format, and checking that wiring for drift, is one
routed flow instead of the three separate hand-built passes this sprint
already needed.

## Gap evidence

- seq:18664 - hook contract parity landed as its own pass: a conformance
  test plus Bash/PowerShell corpus rows proving the same operation classifies
  identically under both shells, with the reach table regenerated by hand
  afterward.
- seq:18670 - a second pass built the typed host-capability matrix (with a
  live-proof column and per-cell reasons) and the `doctor` modules that read
  it, so host health became inspectable only after that landing shipped.
- seq:18868 - a third pass landed `hooks wire --all` itself: dry-run preview,
  marker-delimited merges, a refusal on a malformed config, and a
  stored-region digest check - the actual detect/reconcile/repair mechanics,
  landed after the two passes above already existed.

Three landings, each covering part of the same shape (detect a host, reconcile
its manifest, drift-check it, repair it with a shown diff) without one flow
that walks all four steps in order.

## Promise

Given an installed AI CLI host, this skill reads its current wiring, previews
the exact reconciliation before writing anything, applies only after that
preview is shown, and proves the resulting hook mechanism denies a synthetic
protected operation - stopping and reporting verbatim on any shape it cannot
recover from (a malformed file, an unverifiable gap, a probe that does not
come back `HARD`).

Future edits to this skill append their own seq: citation above.
