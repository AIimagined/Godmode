# Purpose

This skill exists so a spec, its plan, its approval, its bound
implementation, and its status stay one linked record a later session can
resume - instead of divergent drafts of the same document that only get
reconciled by hand, after the fact, once someone notices they disagree.

## Gap evidence

- The same specification was measured at two different line counts within
  the same session, with the second measurement needing to say in prose
  that it "supersedes" the first because an acceptance-clause edit had
  already landed between the two. Two drafts of the same document,
  reconciled only because someone happened to notice the number had moved
  and wrote a correction by hand.
- Defects an earlier assessment had already found in a plan still had to
  be independently reconfirmed from scratch before they counted, because
  the earlier findings were never carried forward as part of the plan's
  own linked record, so the same ground was walked twice.

## Promise

A task's spec and plan move through `specify`, `start`, `check`, `approve`,
`bind`, and `status` as one linked chain: a divergent draft is superseded
with a cited reason instead of a hand-written correction, and a review's
findings are read back from the plan's own record instead of being
reconfirmed from scratch.

Future edits to this skill append their own plain-language evidence above.
